# Bank Data Processing and Decision-Making
# The project is in master Branch
# Description
A project involving data from the banking field (ATB). The data is processed and related using Power BI Query Tool, followed by generating and publishing reports via Power BI Web Publisher. The project includes creating a module to manage reports with user access:

## Features

- 🧩 Process Data in Power BI: Utilize Power BI to process banking data for analysis and reporting.
- 🧩  Relate Data via Query Tool: Use Power BI Query Tool to establish relationships within the data.
- 🧩 Create Reports: Generate comprehensive reports based on processed banking data.
- 🧩 Publish to Power BI Web: Publish the generated reports to Power BI Web for broader accessibility.
- 🧩Create Iframes: Embed reports into iframes for seamless integration into web applications.
- 💾 Develop Interface Application Module: Create an application module to manage report access and visualization.
- 🔍 Admin and Agent Banking Roles: Define roles for admin and banking agents within the application.
- - 🔍 Admin Visualizes All Reports: Allow admins to visualize all reports within the application interface.
- 🔍 Admin Creates Agents and Assigns Interfaces: Enable admins to create agent users and assign specific report interfaces to them.
- 🔍 Save Users in Database: Store user information, including assigned interfaces, in the database.
